# Цель
Разработать доменную модель и консольное приложение учёта парка

## Доменная модель включает:
- **Сущности** — объекты, имеющие уникальную идентичность (ID) и жизненный цикл.
- **Объекты-значения** — неизменяемые объекты, определяемые своими атрибутами, а не идентичностью.
- **Агрегаты** — кластеры сущностей и объектов-значений, которые рассматриваются как единое целое для обеспечения согласованности изменений.
- **Службы домена** — компоненты для реализации бизнес-логики, которая не привязана к конкретной сущности.
- **Доменные события** — уведомления о значимых изменениях состояния в системе.

## Приложение должно делать
- приём техники
- отчёты по числу единиц и суммарной энергии
- список прокатной техники, которая подходит для новичков
- вывод наименования и инвентарных номеров всей техники и вещей

# Требования
- Консольное приложение учёта парка:
    - приём техники
    - отчёты по числу единиц и суммарной энергии
    - список прокатной техники, которая подходит для новичков
    - вывод наименования и инвентарных номеров всей техники и вещей

- Техника попадает в активный парк только после техосмотра
- Нужно видеть суммарное энергопотребление флота
- Нужно понимать, какие устройства можно безопасно выдавать новичкам
- Инвентарные номера обязательны: без них это не кикшеринг
- Тестирование

# Текущие фичи
- на баланс ставятся транспорт и вещи (шлемы, док-станции, зарядные шкафы); сотрудники — нет
- у устройств, потребляющих ресурс, хранится суточный расход энергии (кВт·ч);
- у устройств есть характеристика «простота для новичка» (1–10): при значении ≥ 6 устройство можно выдавать новичкам.

## Будущие расширения
- учёт транспорта
- учёт сотрудников службы эксплуатации
- учёт станций аренды
- учёт склада запчастей
- добавление нового вида транспорта, сотрудника или склада запчастей

# Доманная модель
## Сущности
- Потребители энергии
- Инвентаризируемые объекты с индивидуальными номерами
- Виды транспорта (самокат / велосипед / электровелосипед …), расширяемые
- Сервис техосмотра `ServiceCenter` решает, принимать ли новое устройство в парк
- Небольшая иерархия вещей для апробации (например, шлема, зарядные станции и др, что должно инвентаризироваться)
